# 🧠 알고리즘 스터디 (기초반)

안녕하세요! 알고리즘 스터디에 오신 여러분을 환영합니다 🎉  
효율적이고 꾸준한 스터디 진행을 위해 아래 가이드라인을 참고해 주세요 🙏

## 📅 스터디 개요

- **진행 기간**: 2025.05.07 ~ 2025.07.23 (12주)
- **예상 인원**: 7명
- **진행 방식**:
  - 매일 2~3문제씩 공통 문제 풀이
  - 매일 코딩테스트 풀이 인증
  - 정해진 마감일 전까지 GitHub에 코드 및 간단한 풀이 업로드
- **질의응답 플랫폼**: Slack
- **리뷰 시간**: 매주 특정 날짜에 Zoom 코드 리뷰 및 Q&A 진행 예정

## 🧩 GitHub 사용 규칙

- **업로드 마감**: 매일 오후 11시 59분까지
- **브랜치 전략**: 본인 이름의 브랜치에서 작업 후 커밋
- **커밋 규칙**:
  - **파일명**: `문제이름.py`
  - **커밋 메시지**: `[문제 번호] 문제 이름`  
    예: `[2839] 설탕 배달`
- **풀이 실패 시**: 시도한 흔적 또는 틀린 코드도 함께 업로드해 주세요.

## ❓ 슬랙 Q&A 가이드

- **질문 채널**: `#코딩테스트_스터디_기초반`
- **질문 팁**:
- 접근 방식 공유 요청:  
  > “이 문제 처음 봤을 때 어떤 알고리즘이 떠오르셨나요?”
- 조건 해석 확인:  
  > “인접이라는 조건에 대각선도 포함되나요?”
- 다른 풀이법 비교:  
  > “저는 우선순위 큐로 풀었는데, 정렬로도 가능할까요?”
- 테스트케이스 공유 요청:  
  > “예외적인 테스트케이스 생각나신 거 있나요?”
- 내장 함수 활용법 질문:  
  > “이 문제에서 `any` 또는 `all`을 써보신 분 계신가요?”

- **답변 규칙**:
- 스레드로 답변 남기기
- 해결 완료 시 `✅` 이모지 추가
